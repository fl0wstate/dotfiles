## 📦 Included Configurations

- **Shell**: bash
- **Terminal**: ghostty
- **Editor**: neovim
- **Window Manager**: i3-wm
- **Other**: picom, ranger, rofi
- **Wallpapers**: [Wallhaven](https://wallhaven.cc)

## 🛠️ Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/yourusername/repo.git ~/.dotfiles
   ```

2. Run the copy command to copy all the configurations to your `.config` folder

   ```
   cp -r ./dofiles  $HOME/.config
   ```
